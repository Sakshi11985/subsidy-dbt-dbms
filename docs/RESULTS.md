# Experimental results

Generated by `npm run benchmark` on 2026-10-16 · PostgreSQL 16.15 (Ubuntu 16.15-0ubuntu0.24.04.1) · Node v22.22.0.
Absolute timings depend on the machine; the ratios and the correctness results are what matter.

Dataset: 50,006 citizens, 50,005 parcels, 50,007 ownership rows, 33,344 applications.

## 1. Fraud detection on planted cases (ground truth known)

| Pattern | Planted | Caught by the database |
|---|---:|---:|
| Duplicate bank account (trg_screen_new_citizen) | 30 | 30 |
| Aadhaar reuse (trg_screen_new_citizen) | 20 | 20 |
| Parcel over-allocation (trg_check_parcel_share) | 50 | 50 |

Side effect worth reporting: 200 legitimate registrations with common names raised 103 MEDIUM "similar name" review flags. MEDIUM fuzzy-name flags are review prompts, not blocks. The synthetic data uses only 20x20x15 name combinations, so most new names closely match an existing farmer in the same district; that makes this a pessimistic (high) rate, but common names are also frequent in real villages, which is exactly why name similarity alone must not block a registration.

## 2. Index vs sequential scan (EXPLAIN ANALYZE, median of 7 runs)

| Query | Index | Seq scan (ms) | With index (ms) | Speed-up |
|---|---|---:|---:|---:|
| Duplicate-account lookup (what the screening trigger runs) | uq_bank_account (B-tree, composite) | 3.878 | 0.026 | 149.2× |
| Aadhaar reuse lookup | uq_citizen_aadhaar (B-tree) | 2.792 | 0.014 | 199.4× |
| Fuzzy name match in a district (pg_trgm %) | idx_citizens_name_trgm (GIN, gin_trgm_ops) | 113.303 | 6.393 | 17.7× |
| Parcel share total (ghost-beneficiary trigger) | uq_parcel_citizen (B-tree, parcel_id leading) | 2.118 | 0.025 | 84.7× |
| Verifier queue: status = 'verified' | idx_app_status (B-tree) | 0.02 | 0.024 | 0.8× |

Plans with index: 
- Duplicate-account lookup (what the screening trigger runs): `Index Scan (uq_bank_account)`
- Aadhaar reuse lookup: `Index Scan (uq_citizen_aadhaar)`
- Fuzzy name match in a district (pg_trgm %): `Bitmap Heap Scan → BitmapAnd → Bitmap Index Scan (idx_citizens_name_trgm) → Bitmap Index Scan (idx_citizens_district)`
- Parcel share total (ghost-beneficiary trigger): `Aggregate → Index Scan (uq_parcel_citizen)`
- Verifier queue: status = 'verified': `Limit → Seq Scan`
